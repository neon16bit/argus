## Features

- Open Directory Indexing: Scan, index, and organize media libraries hosted across open directories and HTTP file servers.
- Fetch metadata, thumbnails, and other details for indexed media.
- Video Player: Powered by media_kit for smooth playback. Supports multiple formats, audio tracks, and embedded subtitles.
- Fast Local Database: Built on SQLite and drift for fast search.
- Material 3 UI with Catppuccin themes and dynamic colors.
